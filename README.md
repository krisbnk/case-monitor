# case-monitor

Personal, non-commercial, read-only monitoring tool.

Collects public news and discussion about an unsolved 1990 museum art theft
from official APIs and RSS feeds (Reddit, Wikipedia, GDELT, news alerts),
scores relevance with fixed rules and stores matches in a private database
for manual review.

- Read-only: no posting, voting or messaging
- No user profiling
- Respects API rate limits and terms of use

Status: in development.
